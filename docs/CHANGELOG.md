# 更新记录

## 0.4.8

- 新增 Orca 项目声音插件，以项目 ID 映射独立自定义宿主，工作区与智能体继承项目声音，通过本机 CLI 提交通知，无需 HTTP 或修改智能体 hook。
- 新增 `--profiles` 安全列出声音，以及 `--configure-host` 幂等创建／显式绑定声音；重复同步保留已有声音、台词、音效、显示名和静音，写入继续使用现有锁、冲突检查与备份。
- 事件按工作区项目归属路由，不使用当前焦点猜测；首次状态只建立基线，主智能体结果优先，取消与普通等待不误报成功。同会话不同轮次保留独立事件身份。
- 修复真实 Orca 事件标识与工作区列表标识不同导致漏通知的问题，以终端成员关系还原项目；重载时读取真实智能体快照，不补播历史完成，也保留在途任务的后续状态通知。接入子代理结束（窗格结束而主智能体仍在工作）与子代理等待输入。8 项插件回归、类型检查及官方插件检查通过；OMP 真实会话完成自动播放，待处理／子代理／失败经真实 worker→CLI→播放链路逐一确认出声。
- 同步按项目名为空台词播种“项目名＋状态”提示语并自动渲染缓存，各项目播自己的名字，不再共用声音预设的默认台词；`--configure-host` 新增可重复 `--text <状态> <台词>`，仅写入空台词不覆盖手工配置，播种同样持久化。插件可向上自动定位 `AgentVoice.exe` 并写入自身设置，支持正式安装运行；安装版已经真实智能体完成事件验证自动播报项目名。
- 插件同步新增 `workspace.changed` 订阅（0.1.1）：新打开的目录项目不再依赖第一个状态事件才建宿主，进入 Orca 项目列表即自动创建绑定、播种台词并渲染；同会话不同轮次仍保留独立事件身份。
- 插件播种台词改为更自然的口语句式（0.1.2），如「项目名，全部做完了」；台词仍只写空位。已内置六个 Kokoro 精选音色（晓禾、晴音、若晴、知夏、云舟、远川）预置提示音，可用 `--configure-host <宿主ID> --profile <声音ID>` 或「宿主声音」页按项目换声。
- 专属台词支持多行随机池（0.1.3）：`route.text` 每行一句、播放随机选，`--text` 同一状态可重复传多条合并成池，`warm_cache` 按行渲染；GUI「宿主声音」专属台词框改为多行。插件按项目播种 4～6 句不同口吻的台词（含俏皮语气），用户手写台词永不被覆盖。
- 新增「项目声音」设置面板（0.1.4）：右侧栏铃铛图标打开，可开关通知、按项目/状态换声音、试听、同步项目、打开配置中心、填写 exe 与配置根目录；子代理结束延迟 4 秒与主任务完成合并，一次任务只响一声。
- 播种标记与扩池（0.1.5）：`route.seeded`/`host.name_seeded` 记录插件播种的台词与宿主名，项目改名后同步自动换新名台词，GUI 手写台词与名称永不覆盖；每个状态的台词池扩至 6~10 句，随机取句改用计数器伪随机，分布均匀不连重。
- 台词池扩至 9~15 句/状态（0.1.6）：长短混合、语气梯度拉开，完成 15 句、出错 14 句、待处理 14 句、子代理 9 句。
- 便携包附带插件源码、安装说明和项目隔离回归用例。
- SAPI 兜底与发布就绪（0.1.7）：未找到 `AgentVoice.exe` 时插件照常同步项目绑定，播报回退 Windows 系统语音（固定文案、单一音色），装回 exe 重新同步即恢复完整音色；SAPI 不可用则记录一次错误后静默后续，不反复报错。清单补齐 `author`/`license`/`repository`/`homepage`/`icon` 上架字段；插件已发布至 `github.com/esseener/agent-voice`（tag `v0.1.7`），Git 直装 `orca plugin install esseener/agent-voice` 可用，社区目录经 `orca-plugin` topic 自动收录排队中。

## 0.4.7

- 缓存按真实 WAV / MP3 格式验证；后台加目标文件锁重建，临时输出验证后原子发布。本地通知遇到损坏缓存立即预置回退，应用缓存播放失败安全失效并最多回退一次；用户音效不被删除或改写。缩放提示缓存包含完整源音频内容身份，避免同长度资源更新后误用旧音频。
- GUI 与无界面服务共用单消费者、16 条有界通知队列，满时 HTTP 返回 429、执行器断开返回 503；队列等待超过 30 秒取消并记日志。HTTP 使用固定四连接工作线程；跨进程通知处理最多 17 个活动或等待项，防止后台线程与播放等待无限增长。
- 配置保存及宿主接入 / 移除以规范化目标路径为键加跨进程锁，在锁内重新读取、校验冲突、备份并原子替换；过期草稿、损坏 JSON 与读取错误不覆盖现有文件，宿主更新保留最新无关设置。缓存、队列和并发保存新增隔离回归覆盖。

## 0.4.6

- 台词预热逐条隔离失败，继续处理剩余预设及宿主台词；状态栏显示处理结果和首条错误，完整报告原子写入 `cache-preparation.json`。`--warm-cache` 返回结构化失败列表，部分失败时退出码非零。
- 通知去重改为同事件跨进程互斥、成功播放后记账；失败不再占用合并窗口，允许相同事件重试。
- CLI 和 HTTP 支持可选的 `event_id` / `session_id`，并贯通 hook 输入、隐藏播放进程和活动日志；没有身份的旧调用保留原有合并规则。
- OpenCode 插件传递逻辑事件身份，合并进行中的请求，仅在播放进程成功退出后记录事件；失败的播放或进程启动允许上游重放重试。
- 构建脚本使用 .NET 流式 SHA-256 为旧 EXE 归档，不再依赖当前 PowerShell 中可能不可用的 `Get-FileHash`。

## 0.4.5

- 加固本地 HTTP 事件接口：先校验请求行与 Bearer 密钥再检查消息框架；缺失 Content-Length 返回 411、格式错误返回 400、超过 12288 字节仍返回 413，拒绝重复 Content-Length 与 Transfer-Encoding 请求。
- 提升接口可靠性：accept 瞬时错误不再终止监听线程；响应后先发送 FIN 并短暂读尽残留数据，避免 Windows 在尚有未读数据时以 RST 关闭而丢弃已写出的响应。Bearer 方案名按 HTTP 规范大小写不敏感解析。
- 为接口新增环回端到端测试，覆盖帧错误矩阵、202 入队与 429 队列满。

## 0.4.1

- 本地任务通知不在触发后加载模型或合成；原台词缓存缺失时直接播放对应状态的预置提示，不延迟补播原句。
- 随包增加六种声音、四种状态的 24 条 Kokoro 音频，约 3 MB；无模型驻留、缓存为空或 GUI 关闭也能播放。
- 试听与后台制作音频不占播放锁；HTTP 通知独立处理，避免等在模型加载之后。已有声音正在实际播放时仍顺序播放。
- 后台准备覆盖全部固定台词与宿主覆盖台词，移除每轮 64 条上限；保留音量、静音、配置和绑定。

## 0.4.0

- 默认离线模型更换为 Kokoro-82M v1.1-zh INT8，原生 24 kHz，支持中英混读，替换 8 kHz AISHELL3 VITS。
- 六个固定入口改为新模型的独立声音；默认保留原速、原调、原始停顿与较轻的压缩，移除不适用的 VITS 变化控制。
- 旧本地声音按性别转换为新模型草稿，保留名字、台词、音量、静音与宿主绑定，保存前不改写配置；缓存独立升级。
- 发布包仅含一个新模型；旧资源与发布包保留供旧窗口使用。模型权重约 114 MB，完整资源约 225 MB，首次及未缓存 CPU 合成比旧版慢。
- 打包按资源清单递归包含词典，统一 ZIP 路径并逐文件核验；随包提供新声音目录、参数与说明。

- 修复小写及混合大小写的助手名称被逐字母拼读，旧音频缓存自动失效。

## 0.2.0

- 为全部 174 个本地音色增加中文昵称、官方性别和原始说话人编号；支持男女声筛选与收藏。
- 新增原生调音台：滑杆和数字框同步、自动响度补偿、-12～18 dB 增益、三段均衡、动态压缩、前瞻限幅，以及 VITS 音色 / 节奏变化和停顿控制。
- 提供六组应用调音方案和官方参数对照，支持保存自定义、JSON 导入 / 导出；试听显示语音段响度与峰值。预设来源和 8 kHz 音质边界在说明中列明。
- 调音参数参与音频缓存，新版自动避开旧的偏小音频；已有配置兼容加载，新增设置使用默认值。
- 版本统一从 Cargo.toml 读取，Windows 清单不再固定版本；后续迭代同步窗口、文件属性和发布包，保留历史发布。

## 0.1.0

- 只内置一个约 30 MB 的 VITS AISHELL3 本地中文模型，174 个说话人共用；完整 CPU 资源约 49 MB，解压即用，无需 Python 或模型服务。
- 新声音默认离线；新增随机本地音色。按需加载、两个 CPU 线程、闲置约 30～35 秒释放模型。
- 启动和保存后准备固定台词缓存；缓存只依赖音频参数和正文，改名或改其他事件台词不再重复合成。在线事件合成超时从 60 秒缩短为 8 秒。
- 全面替换为新版双音符芯片 Logo，应用顶部、标题栏、任务栏和 EXE 统一为白色透明图形；补齐完整、精简、横版、竖版及文字标识，随便携包提供。
- 应用顶部使用 256 px 原图绘制，改善高 DPI 清晰度；小图标按尺寸提取新版芯片主体。
- 首页明确为「宿主声音 / 选择宿主」，与可复用的「声音预设」分开；返回时保留所选宿主。
- 任务栏使用芯片双音符主图形，补齐 10 种 ICO 尺寸，并为标题栏和任务栏按 DPI 分别加载，避免缩放发虚。
- 改为 Rust + Win32 原生独立 EXE，内置在线合成、Windows 离线语音和音频播放。
- 新增 ChatGPT、Codex、Gemini CLI、Cursor 等宿主与本机自动扫描。
- 每个宿主的四种状态独立选择声音、台词、静音和本地音效。
- 支持添加自定义宿主、命令触发，以及带密钥的本地 HTTP 事件接口。
- 声音删除可解除绑定并静音受影响状态；旧配置迁移到独立 .agent-voice 目录。
- 深黑与白色桌面界面，区分声音工作台和宿主接入。
- 透明底白色 Logo，统一应用内、窗口、任务栏和 EXE 图标。
- 可编辑音色、语速、音高和事件台词，支持单句及随机试听。
- 声音配置支持新增、重命名、静音和删除；使用中的配置会提示先处理宿主绑定。
- 保存前自动备份并检查外部改动，宿主接入保留其他工具的设置。
- 工作区整理为源码、资源、文档、测试、构建工具和旧版归档。
- 应用界面、Windows 文件属性和便携发布包统一版本为 0.1.0。
