# 声音库与调音台

> 本文保留旧 AISHELL3 版本的调音说明。0.4.0 已更换为 Kokoro，当前声音、默认参数和可用控制见 [KOKORO_VOICE.md](KOKORO_VOICE.md)。

「声音预设」默认显示「精选声音」，直接试听卡片上的固定组合，满意后点击「使用这个声音」并保存。「音色与台词」保留完整音色筛选和台词编辑，「调音台」提供进一步调整。所有本地音色仍共用一个约 30 MB 的 AISHELL3 模型。

精选组合引用官方文档里的示例说话人，搭配本应用固定参数，语速和音高回到原值，停顿保持 100%。卡片的「试听」不会更改当前配置；「使用」保留你的名称、台词、最终音量和宿主绑定。「稳定当前音色」只恢复播报参数，不换说话人。「下一个精选组合」按固定顺序切换，不再随机抽取 174 种声音。

## 音色名称

174 种音色都有中文昵称，同时显示男声 / 女声、模型编号与原始 `SSB` 编号。昵称用于记忆，不是真人姓名。性别来自 AISHELL-3 公开说话人资料，模型编号来自随模型提供的 `speakers.txt`，包含 138 个女声、36 个男声。

下拉框左侧可筛选男女声、官方示例中使用的音色、收藏和在线 / 系统声音。切换筛选时保留当前音色，避免误改；当前音色可能临时显示在不匹配筛选条件的列表首行。收藏后可快速找到喜欢的音色。

常用编号现在对应：010 景川（男声）、021 景辰（男声）、033 听晓（女声）、041 若音（女声）、045 若宁（女声）、066 沐秋（女声）、099 清岚（女声）、103 清宁（女声）。已有预设的编号保持不变，因此同一个声音不会因新增昵称而换人。

## 先解决小声

此前音量 100 只是乘以 1，保留了模型本身的响度差异。现在默认开启自动响度补偿，按有效语音段的 RMS 将声音调整到约 -18 dBFS。它不是 LUFS 标准化。极轻的输入最多补偿约 30 dB，数字静音不会被放大成噪声。

音量 0～100 是最终输出比例；「增益」另提供 -12～+18 dB。想更响可以用「强力提醒」，或开自动响度、增益 +3～+6 dB、动态压缩 50～75。峰值保护始终启用，5 毫秒前瞻、80 毫秒释放、采样峰值上限 -1 dBFS；它防止数字削波，不会调高 Windows 总音量或设备音量。试听完成后，底部显示该条音频的语音段响度与采样峰值，方便比较。

## 参数与作用

| 控制 | 范围 | 作用 |
| --- | --- | --- |
| 语速 | -40～40% | 模型生成速度，0 为原速 |
| 音高 | -40～40 | 本地重采样移调，并通过合成速度补偿时长；大幅调整会更有电子感 |
| 音量 | 0～100% | 所有处理后的最终输出，0 为静音 |
| 增益 | -12～18 dB | 在响度补偿和压缩后额外增减音量 |
| 低频 | -12～12 dB | 180 Hz 低架均衡，增加厚度或减少闷声 |
| 清晰度 | -12～12 dB | 1500 Hz 人声均衡，适量增加可提升存在感 |
| 高频 | -12～12 dB | 2700 Hz 高架均衡，增加明亮感或减少刺耳 |
| 动态压缩 | 0～100 | 减少轻重音差异；越大越紧实，过大可能不自然 |
| 音色变化 | 0～100 | VITS 的 noise_scale，数值越大，生成变化越多；67 对应官方 0.667 |
| 节奏变化 | 0～100 | VITS 的 noise_scale_w，调整时长预测的变化；80 对应官方 0.8 |
| 停顿 | 0～200% | 按当前语音响度检测持续至少 300 ms 的极轻空隙，缩放后两侧各保留 80 ms；100 为完整保留原停顿 |

0 的变化使用接近零的正值，避免 C API 将零解释成默认值。改变音色或节奏变化需重建模型实例，因此首次试听会多一次加载；停顿、均衡、增益和压缩不重载模型。模型始终只有一份，仍使用两个 CPU 线程，闲置后释放。

0.3.0 修复了轻声音色被错误截断的问题：固定运行库的 `ScaleSilence` 使用绝对 0.01 阈值，低于该阈值的轻声部分可能被当成停顿。现在运行库始终保留原始音频，由应用按相对响度处理真实空隙，再做响度补偿。旧配置无需重填，旧缓存自动避开。`codex`、`Claude`、`open code` 等常见名称也按不区分大小写的中文读法转换。

## 可直接套用的预设

提供清晰播报、温和陪伴、明亮轻快、低沉稳重、强力提醒、俏皮助手，以及原声对照（官方参数）。前六项是 Agent Voice 的应用调音配置；预设 JSON 保留来源。原声对照采用官方 noise_scale=0.667、noise_scale_w=0.8、length_scale=1 和原停顿，关闭自动响度、均衡和压缩，仍保留峰值保护。

核对的官方资料与社区示例主要提供说话人编号、语速和基础参数，没有找到可确认适配此小模型的完整情绪预设包。因此没有把其他模型的角色权重或情绪标签混进来。这里的风格名称表示参数组合，不等于模型理解了“开心”“悲伤”等情绪。

在名称框输入如「我的提醒」，点击「保存为预设」即可复用当前语速、音高和全部调音参数。同名自定义预设会更新。预设不改变原音色、最终音量、台词或宿主绑定。导出生成当前参数的 JSON，导入可读取其他人分享的同格式文件；便携包 `VoiceLibrary/调音预设.json` 包含全部内置参数。

## 音质边界

这个小模型原生输出为 8 kHz，适合轻量中文提示。响度和均衡可以改善听感，但无法补回原本不存在的高频细节，不能把它调成高采样率大模型的音质。
